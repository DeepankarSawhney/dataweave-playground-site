Quick start

Up and running in under 30 seconds

1

Pull & run

One command pulls the image and starts the server. Works on Linux, macOS, and Windows.

terminal
$ docker run -p 3000:3001 \
deepankar2810/dataweave-playground
Starting DW Playground…
✓ Listening on port 3001
2

Open your browser

Navigate to localhost:3000. The playground loads with a Monaco Editor and six built-in examples to get you started.

localhost:3000
3

Write & transform

Type your DataWeave script, paste any input payload, choose your format, and hit Ctrl+Enter or click Run.

%dw 2.0
output application/xml
---
{ root: {
message: upper(payload.text)
} }
→ ✓ output · XML · 118ms

Convert a JSON product list into an XML catalog with attributes Input: JSON · Output: XML
Script
%dw 2.0
output application/xml
---
{
catalog: {
(payload map (item) -> {
product @(id: item.sku,
inStock: item.inStock): {
name: item.name,
price: item.price
}
})
}
}
Input · JSON (payload)
[
{
"sku": "A100",
"name": "Widget Pro",
"price": 29.99,
"inStock": true
},
{
"sku": "B200",
"name": "Gadget Plus",
"price": 49.99,
"inStock": false
}
]
Output ✓ OK
<?xml version='1.0' encoding='UTF-8'?>
<catalog>
<product id="A100" inStock="true">
<name>Widget Pro</name>
<price>29.99</price>
</product>
<product id="B200" inStock="false">
<name>Gadget Plus</name>
<price>49.99</price>
</product>
</catalog>
Parse a CSV of student scores, cast types, and assign letter grades Input: CSV · Output: JSON
Script
%dw 2.0
output application/json
---
payload map (row) -> {
id: row.id as Number,
name: upper(row.name),
score: row.score as Number,
grade:
if (row.score as Number >= 90) "A"
else if (row.score as Number >= 80) "B"
else "C"
}
Input · CSV (payload)
id,name,score
1,alice,92
2,bob,78
3,carol,85
4,dan,90

Features

Everything you need for local DataWeave development

⚡

Sub-200ms transforms

All three engine versions (DW 2.11, 2.6, 2.3) are pre-warmed at startup so every request is fast — no cold-start delays.

🧩

Monaco Editor

Three-panel layout (Script · Input · Output) with resizable dividers, DataWeave syntax highlighting, and Ctrl+Enter shortcut.

📂

Multiple named inputs

Add extra inputs beyond payload using tabs. Each input has its own format selector — mix JSON, XML, and CSV in one transform.

🔢

Three DW versions

DW 2.11, 2.6, and 2.3 come pre-installed. Download additional versions on demand straight from the version dropdown — no restart needed.

💡

Context-aware autocomplete

Suggestions filtered by inferred data type (Array, Object, String, Number) based on the expression context and your actual input payload.

💾

Import / Export workspaces

Save your entire workspace — scripts, inputs, and settings — as a .dwproject.json file. Six built-in starter examples included.

Releases

Latest

v1.0.12

View on Docker Hub →
  • ⚡Faster transforms: DW 2.11 transforms drop from 2–5s to ~150ms — a persistent JVM engine stays warm between runs so there's no cold-start wait.
  • 🔄Auto-recovery: If the engine hits an unexpected crash, it automatically restarts with exponential backoff — no container restart needed.
  • 🧹Better resource cleanup: Temporary files are cleaned up on startup, shutdown, and after 30 minutes of idle — no more orphaned files burning container memory.

View on Docker Hub →
