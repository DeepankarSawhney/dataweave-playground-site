DataWeave Playground
on your machine

A full-featured clone of the MuleSoft DataWeave Playground that runs entirely in Docker. Write DW 2.0 transformations, supply any input format, and see the output instantly — with no cloud dependency or MuleSoft account.

$ docker run -p 3000:3001 deepankar2810/dataweave-playground:latest

Then open http://localhost:3000

Features

Everything you need for local DataWeave development

⚡

Fast transforms

Persistent JVM sidecar for DW 2.11 delivers sub-200ms responses on all requests — as fast as the online playground.

🧩

3-panel editor

Script, Input and Output panels with draggable dividers. Monaco Editor (VS Code engine) with DataWeave syntax highlighting.

📂

Multiple inputs

Add named inputs beyond the default payload using tabs. Each input has its own format selector.

🔢

Multiple DW versions

Three versions pre-installed (2.11, 2.6, 2.3). Download additional versions on demand straight from the version dropdown.

💡

Context-aware autocomplete

Suggestions filtered by inferred data type (Array, Object, String, Number) based on the expression and your actual input payload.

💾

Import / Export

Save and restore your entire workspace as a .dwproject.json file. Six built-in starter examples included.

Roadmap

What's coming in future releases

In Progress

JVM Sidecar for DW 2.11

Persistent JVM engine replaces per-request GraalVM process spawns — brings DW 2.11 response times from ~2–5s down to ~150ms.

Planned

Performance improvements

Brotli pre-compression for static assets, response caching for identical transforms, connection keep-alive tuning.

Planned

Script history

Local browser-based history of recent scripts so you can quickly revert or replay a previous transformation.

Planned

Shareable workspace links

Encode script + input into a URL fragment so you can share a complete playground state with a single link.

🐛

Found a bug?

Open a GitHub issue and include the DW version, your script, input, and what you expected vs what happened. Requests for new features and format support are welcome too.
